Comprehensive Survival Analysis Pipeline with ml4time2event

This vignette demonstrates an end-to-end survival analysis workflow using the ml4time2event package. We rely on the prepared NCCTG lung cancer dataset distributed with the package, build an ensemble of survival models, evaluate performance, and visualise predictions.

1. Setup and Load Libraries

library(ml4time2event)
library(survival)
library(dplyr)
library(ggplot2)

2. Load Prepared Dataset

The dataset lung_survival_prepared ships with the package and contains the imputed and feature-engineered variables used throughout this vignette.

5. Data Splitting

split_data <- t2edata_split(lung_data, prop = 0.7)
train_data <- split_data$Train
test_data <- split_data$Test

6. Survival Model Training

timevar <- "time"
eventvar <- "status"
expvars <- c("age", "sex", "ph.ecog", "ph.karno", "meal.cal", "wt.loss")

models <- RunSurvModels(
  datatrain = train_data,
  ExpVars = expvars,
  timevar = timevar,
  eventvar = eventvar,
  models = c("glmnet", "coxph", "rulefit", "xgboost", "gam", "gbm", "ExpSurvReg", "bart", "shallownn", "ttah"),
  ntimes = 50
)

7. Predictions

complete_test_data <- test_data[complete.cases(test_data[, expvars]), ]
prediction_times <- sort(unique(complete_test_data[[timevar]]))

# Generate predictions
predictions <- PredictSurvModels(
  models = models,
  newdata = complete_test_data,
  new_times = prediction_times,
  ensemble_method = "average"
)

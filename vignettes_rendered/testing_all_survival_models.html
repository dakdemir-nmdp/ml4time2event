Overview

This vignette demonstrates testing all available survival models in the ml4time2event package with a simple example. We will use a small subset of the lung cancer dataset to quickly fit, predict, and evaluate all survival models, ensuring the complete pipeline works correctly.

1. Packages and data

library(ml4time2event)
library(dplyr)
library(ggplot2)
library(survival)

Load the lung cancer dataset and create a small subset for testing:

# Load the full dataset
lung_df <- get_lung_survival_data()

# Create a small subset for quick testing (100 observations)
set.seed(42)
small_lung <- lung_df %>%
  select(time, status, age, sex, ph.ecog, ph.karno, wt.loss)

3. Create Survival Task

Create a survival analysis task:

# Create survival task
task <- ml4t2e_task_surv(
  data = small_lung,
  time = "time",
  event = "status",
  features = c("age", "sex", "ph.ecog", "ph.karno", "wt.loss")
)

Fit All Survival Models

Fit all available survival models (excluding GBM which has issues with small datasets):

models_to_fit <- survival_models$engine
models_to_fit <- setdiff(models_to_fit, "gbm") # Exclude GBM explicitly

# Fit all survival models
fitted_models <- ml4t2e_fit(
  task = task,
  models = models_to_fit,
  seed = 42
)

7. Visualize Results

Create a simple visualization of survival curves for a few models:

# Plot survival curves for first few models
plot_data <- predictions %>%
  filter(model %in% c("cox", "random_forest", "xgboost")) %>%
  filter(id == 1) # Focus on one individual

ggplot(plot_data, aes(x = time, y = surv, color = model)) +
  geom_line() +
  labs(
    title = "Survival Curves for Selected Models (Sample Individual)",
    x = "Time",
    y = "Survival Probability",
    color = "Model"
  ) +
  theme_minimal()
